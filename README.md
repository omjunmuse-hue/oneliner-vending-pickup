One pickup line of at most 200 characters that a vending machine would use on a passing human — spoken by the machine itself, out of its own world of slots, buttons, coils and exact change. The program writes the line to /output/entry.txt and an AI judge compares the lines in pairs.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
